# NKRIX — Intelligence Portfolio

> Military / intelligence-agency themed developer portfolio for **Nithish Kumar Reddy** (NKRIX).

## Stack

- React 19 + Vite + TypeScript
- Tailwind CSS 4
- Framer Motion
- Share Tech Mono + Space Grotesk fonts

## Features

- **Access Gate** — visitors register name / org / purpose before entering
- **Boot Sequence** — terminal-style startup animation
- **Custom Cursor** — military targeting reticle with crosshair, corner brackets & live coordinates
- **Matrix Rain** — subtle canvas falling-character background on hero
- **Intel Ticker** — live-scrolling classified signal feed in navbar
- **GlitchText** — section headings scramble on hover before decoding
- **Skill Counter** — proficiency bars animate from 0% on scroll-into-view
- **Rubber Stamp** — classification stamp slams onto project cards on hover
- **Periodic Glitch** — random CRT interference lines flash across viewport
- Phosphor-green terminal colour theme with scanlines + noise overlay

## Run Locally

```bash
npm install
npm run dev
```
